## Agent skills

### Issue tracker

Before reading or writing issues, read `docs/agents/issue-tracker.md`.
Issues and specs are local Markdown files under `.scratch/<feature>/`.

### Triage labels

Before triaging issues, read `docs/agents/triage-labels.md`.
Use the five default triage roles as local issue status values.

### Domain docs

Before exploring the codebase, read `docs/agents/domain.md`.
Use a single-context layout: root `CONTEXT.md` and `docs/adr/`.
