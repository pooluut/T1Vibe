# T1Vibe

在 Windows 上使用 google TV T1 遥控器操作 ChatGPT 桌面应用，支持官方听写、唤起输入框、左侧导航和对话滚动。

目前只测试了 USB 接口，蓝牙未测试

## 按键

| 按键 | 功能 |
| --- | --- |
| 应用图标 / Apps | 唤起 ChatGPT 并聚焦输入框 |
| 语音 | 触发 Windows 听写 Win + H |
| 主页 | 左侧导航，优先当前高亮条目 |
| 上 / 下 | 左侧选择条目或滚动对话 |
| 确认 / Enter | 输入框发送；会话行打开；项目行新建聊天 |
| 返回 | 进入对话浏览 |

## 使用与兼容性

适用 Windows 10/11 x64、.NET Framework 4.8。双击构建后的 `dist/T1Vibe.exe`，右键托盘图标退出。无需旁置 DLL 或开发工具。

目标应用进程名为 `ChatGPT`，启动标识为 `OpenAI.Codex_2p2nqsd0c76g0!App`。其他发行版、界面语言和结构需重新验证。Win + H 须事先可用，输入麦克风由 Windows 设置决定。

语音信号不限制接收器 VID/PID；目前支持 Consumer Control 的 Report ID `02`、16 位小端 Usage `0x00CF` 报告，其他协议需适配。主页和返回原始 HID 按 `VID_1915/PID_1025` 过滤。侧栏只处理可见条目，不自动滚动。

## 构建与测试

将 [Zig 0.13.0](https://ziglang.org/download/) 放在项目的 `tools/ziglang/ziglang/` 下（其中应有 `zig.exe`），在 PowerShell 中运行：

```powershell
./build.ps1
```

脚本使用 Windows .NET Framework C# 编译器和 Zig，仅生成发布程序 `dist/T1Vibe.exe`（中间编译文件放在 `build/`）。重新构建前先退出正在运行的程序。

如需同时运行自动测试，执行 `./build.ps1 -Test`。也可使用 `-Zig` 指定其他编译器路径。默认路径相对脚本所在目录解析，不依赖当前工作目录。`tools/` 不提交到 Git，新电脑构建前需放置 Zig。

自动测试覆盖菜单键过滤、项目新建按钮名称匹配、内嵌模块加载及原生钩子注册和卸载。焦点、真实按键及滚动仍需人工验证：

1. 从其他窗口唤起输入框，测试听写与回车发送。
2. 主页进入侧栏，测试当前项定位、上下移动、会话打开和项目新建聊天。
3. 返回进入长对话浏览，测试上下滚动并回到输入框。
4. 退出后确认默认按键行为恢复。

## 隐私和系统影响

程序不写日志，不保存按键、会话标题或录音，不自行上传内容；Windows 听写使用 Windows 自身的语音服务。

不写注册表，不安装服务或驱动，不添加开机启动。运行时将内嵌钩子释放并校验到 `%TEMP%\T1Vibe\<hash>\HomeHook.dll`；退出会卸载钩子。DLL 可能因其他进程暂时持有而留在临时目录，重启后可清理。

程序运行时，普通键盘的菜单键、浏览器主页/返回键也会被接管；导航模式中的普通键盘上下和回车同样参与处理。退出后恢复。

## 目录

- `src/`：主程序和原生 Shell 钩子。
- `tests/`：回归测试。
- `build.ps1`：构建、测试和打包入口。

构建产物与本地工具由 `.gitignore` 排除。发布程序可将 `dist/` 中的 EXE 上传至 GitHub Releases。项目未指定开源许可证。

Zig 仅在从源码构建时需要，运行打包后的 EXE 不需要 Zig、Visual Studio 或其他开发工具。
