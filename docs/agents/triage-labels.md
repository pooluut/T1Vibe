# Triage Labels

Use this mapping when a skill refers to a canonical triage role.
For this local tracker, record the mapped value in the issue's
`Status:` line.

| Canonical role | Local status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer needs to evaluate the issue |
| needs-info | needs-info | Waiting on the reporter for more information |
| ready-for-agent | ready-for-agent | Fully specified, ready for an autonomous agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |
